NeuralHub AI Marketplace

Platform marketplace AI berbasis web yang menghubungkan pengguna dengan model kecerdasan buatan melalui antarmuka terintegrasi, didukung blockchain untuk transparansi dan keamanan log inferensi.

Laravel 12 PHP 8.2+ FastAPI Python + Groq LLaMA 3.3 70B Solidity Ganache (Ethereum) Tailwind CSS 4 MySQL / SQLite
Lihat di GitHub

Masalah

Fragmentasi Akses Model AI

Pengguna tidak memiliki platform terpusat untuk mengakses berbagai model AI analisis teks. Setiap layanan berdiri sendiri tanpa audit trail yang bisa dipercaya, sehingga mengakibatkan:

  • Tidak ada satu platform untuk berbagai model NLP
  • Tidak ada transparansi dan verifikasi hasil inferensi AI
  • Manajemen kredit dan API key yang rumit dan terpencar
  • Tidak ada riwayat request yang terverifikasi dan tidak bisa dimanipulasi

Solusi

Marketplace AI Terintegrasi + Blockchain

NeuralHub menyatukan katalog model AI, eksekusi inferensi via Python FastAPI, dan pencatatan hasil ke smart contract Ethereum, sehingga:

  • Pengguna dapat mengakses berbagai model AI dari satu platform
  • Setiap inferensi dicatat ke blockchain (immutable log) sebagai bukti audit
  • Sistem kredit dan API key management terintegrasi dalam satu dasbor
  • Riwayat request real-time dilengkapi tx_hash dan block_number blockchain

Alur Kerja Sistem

Alur Pengguna

1

Daftar atau Masuk

Buat akun (dapat 100 kredit gratis) atau masuk untuk mengakses platform

2

Pilih Model AI

Jelajahi katalog: Sentiment Analyzer, Spam Detector, atau Fake News Detector

3

Kirim Teks

Input teks (maksimal 5.000 karakter) via halaman /demo atau /analyze

4

Sistem Memproses

Laravel meneruskan ke Python FastAPI → Groq LLaMA 3.3 → catat ke blockchain

5

Terima Hasil

Dapatkan label, confidence %, penjelasan, dan tx_hash blockchain sebagai bukti

Alur Inferensi AI (Backend)

1

Validasi & Cek Kredit

AiRequestController memvalidasi input dan memeriksa saldo kredit user

2

Buat Record Pending

AiRequest::createPending() simpan ke database dengan status "pending"

3

Panggil Python FastAPI

Http::timeout(10)->post() ke endpoint model (sentiment / spam / fakenews)

4

Catat ke Blockchain

BlockchainService::addLog() kirim JSON-RPC ke Ganache smart contract AILog.sol

5

Kurangi Kredit & Response

user->deductCredit() lalu kembalikan hasil + tx_hash ke pengguna

Fitur Utama

Autentikasi Pengguna

Sistem login dan registrasi aman menggunakan Laravel Sanctum dengan kontrol akses berbasis peran: user, developer, dan administrator.

Katalog Model AI

Tiga model AI siap pakai: Sentiment Analyzer (94.2%), Spam Detector (97.8%), dan Fake News Detector (88.5%), dikelola via tabel ai_models.

Manajemen Request & Riwayat

Lacak seluruh riwayat inferensi secara real-time dengan status (pending, success, failed), response time, confidence, dan tautan ke bukti blockchain.

Integrasi Blockchain

Setiap hasil AI dicatat ke smart contract AILog.sol di Ganache via JSON-RPC. Menghasilkan tx_hash dan block_number sebagai bukti audit yang tidak dapat dimanipulasi.

Sistem Kredit

Pengguna mendapat 100 kredit gratis saat mendaftar. Setiap inferensi sukses mengurangi 1 kredit. Kredit hanya terpotong setelah seluruh pipeline berhasil dijalankan.

API Key Management

Generate dan kelola API key (64 karakter random) untuk akses programatik. Satu user bisa memiliki banyak key dengan fitur revoke dan tracking last_used_at.

Tantangan & Pembelajaran

Hubungan Database Kompleks

Tantangan: Mengelola relasi antar lima tabel (users, ai_models, ai_requests, blockchain_logs, api_keys) sambil menjaga integritas data dengan cascade delete yang tepat.

Solusi: Menerapkan foreign key constraints, cascadeOnDelete(), dan Eloquent relationships (belongsTo, hasMany, hasOne) yang terdokumentasi lengkap per model.

Kontrol Akses Berbasis Peran

Tantangan: Menerapkan tiga tingkat akses (user, developer, admin) dengan otorisasi yang tepat menggunakan Laravel Sanctum.

Solusi: Membuat middleware untuk pemeriksaan peran, menggunakan helper isAdmin() dan isDeveloper() pada model User, serta route group dengan middleware 'auth'.

Integrasi Blockchain Tanpa Library

Tantangan: Mengintegrasikan smart contract Ganache ke Laravel tanpa library web3.php — harus melakukan ABI encoding secara manual menggunakan keccak256 function selector.

Solusi: Menggunakan Laravel HTTP Client langsung ke JSON-RPC Ganache. Encode ABI manual (4-byte selector + offset + string params). Fallback simulasi tx_hash jika Ganache offline agar aplikasi tetap berjalan.

Konsistensi Output LLM

Tantangan: Respons LLM (Groq LLaMA 3.3) tidak selalu dalam format JSON yang konsisten — terkadang terdapat markdown fence (```json), whitespace, atau format yang tidak sesuai ekspektasi.

Solusi: Prompt engineering ketat ("Reply ONLY in this exact JSON format"), post-processing dengan removeprefix/removesuffix untuk strip markdown fence, serta HTTPException 500 informatif jika parsing gagal.

Orkestrasi Multi-Service

Tantangan: Menjalankan tiga server secara bersamaan (Laravel, Python FastAPI, Ganache) dan memastikan ketiganya dapat berkomunikasi dengan andal dalam satu alur transaksi.

Solusi: Konfigurasi via .env (PYTHON_API_URL, GANACHE_URL), Http::timeout(10) untuk graceful failure, dan fallback mechanism di BlockchainService sehingga kegagalan satu service tidak menghentikan keseluruhan aplikasi.
