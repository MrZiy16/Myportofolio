JASPAY

Platform SaaS booking jasa lokal Indonesia dengan fitur manajemen bisnis, AI insights prediksi jadwal ramai, dan notifikasi WhatsApp otomatis untuk salon, laundry, servis AC, dan fotografer.

Next.js Express.js PostgreSQL Prisma Docker Tailwind CSS WhatsApp API AI/ML
Lihat di GitHub Demo Langsung

Masalah

Manajemen Bisnis Jasa Manual

UMKM jasa di Indonesia masih mengandalkan WhatsApp dan Excel untuk operasional sehari-hari. Masalah yang dihadapi:

  • Booking via WhatsApp manual, sering bentrok jadwal
  • Data pelanggan tersebar di chat dan Excel
  • Tidak ada reminder otomatis ke customer
  • Owner tidak tahu kapan bisnis ramai atau sepi
  • Invoice dibuat manual satu per satu
  • Tidak ada laporan pendapatan yang jelas

Solusi

Platform Booking Jasa All-in-One

Platform SaaS yang mengotomatisasi seluruh operasional bisnis jasa UMKM:

  • Sistem booking online dengan cek slot otomatis
  • CRM pelanggan terpusat dengan histori lengkap
  • Reminder H-1 otomatis via WhatsApp
  • AI prediksi jadwal ramai & estimasi pendapatan
  • Invoice digital otomatis
  • Dashboard owner real-time

Tantangan & Pembelajaran

Integrasi WhatsApp API

Tantangan: Setup Fonnte API dengan CORS dan token management yang kompleks.

Solusi: Custom middleware CORS + environment variable management di Docker.

AI Prediksi Jadwal

Tantangan: Membuat prediksi akurat dengan data booking yang masih terbatas.

Solusi: Time series analysis berbasis histori booking dengan fallback ke statistik sederhana.

Docker di Windows

Tantangan: Volume mounting dan path issues saat development di Windows.

Solusi: Custom docker-compose dengan explicit volume mapping dan permission fix.

PWA Setup di Next.js 16

Tantangan: Konfigurasi manifest dan service worker di Next.js versi terbaru.

Solusi: Custom layout dengan meta tags manual + konfigurasi next-pwa yang disesuaikan.

Prisma v7 Breaking Changes

Tantangan: Konfigurasi datasource berubah signifikan di Prisma versi 7.

Solusi: Migrasi ke prisma.config.ts dengan defineConfig dan datasource baru.
