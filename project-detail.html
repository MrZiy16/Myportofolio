The Problem

Manual Order Management

Many catering businesses still manage orders manually via WhatsApp or phone calls, making it difficult to track orders and payments efficiently. This leads to:

  • Order confusion and missed deadlines
  • Difficulty tracking payment status
  • Poor customer communication
  • Time-consuming administrative work

The Solution

Integrated Online Platform

The Kemuning Catering Management System provides a complete online ordering platform where:

  • Customers can browse and select catering packages
  • Orders are placed and tracked in real-time
  • Payment proof can be uploaded directly
  • Admins manage orders through an intuitive dashboard
  • Automated notifications keep everyone informed

Database Design

The system uses a relational database with carefully designed tables to manage users, products, orders, and payments. The database follows normalization principles to ensure data integrity and optimal performance.

Users Table
id INT (PK)
name VARCHAR
email VARCHAR (UNIQUE)
password VARCHAR
role ENUM
phone VARCHAR
Products Table
id INT (PK)
name VARCHAR
description TEXT
price DECIMAL
category VARCHAR
image VARCHAR
Orders Table
id INT (PK)
user_id INT (FK)
total_price DECIMAL
status ENUM
delivery_date DATE
created_at TIMESTAMP
Payments Table
id INT (PK)
order_id INT (FK)
amount DECIMAL
proof_image VARCHAR
status ENUM
verified_at TIMESTAMP

Database Relationships

  • Users → Orders: One-to-Many (One user can have multiple orders)
  • Orders → Order Items: One-to-Many (One order can have multiple items)
  • Products → Order Items: One-to-Many (One product can be in multiple orders)
  • Orders → Payments: One-to-One (Each order has one payment record)

Challenges & Learning

Database Relationships

Challenge: Managing complex relationships between orders, order items, products, and payments while maintaining data integrity.

Solution: Implemented proper foreign keys, cascading deletes, and used Eloquent relationships to handle the complexity elegantly.

File Upload Handling

Challenge: Implementing secure file upload for payment proof with validation and storage.

Solution: Used Laravel's file storage system with proper validation, virus scanning, and organized file structure.

Role-Based Access Control

Challenge: Implementing different access levels for customers and administrators with proper authorization.

Solution: Created middleware for role checking and used Laravel's built-in authorization features.

Performance Optimization

Challenge: Optimizing database queries for dashboard with large datasets.

Solution: Implemented eager loading, query optimization, and database indexing strategies.

Responsive Design

Challenge: Creating a responsive interface that works seamlessly on mobile and desktop.

Solution: Used Bootstrap 5 grid system and custom CSS media queries for optimal experience.

Real-Time Notifications

Challenge: Implementing real-time notifications for order updates.

Solution: Used Laravel events and listeners with session-based notifications for instant updates.
