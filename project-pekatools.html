Masalah

Tools Online Sering Ribet & Gak Bisa Dipercaya

Kebanyakan tool produktivitas online (compress gambar, edit PDF, generate QR) punya masalah yang sama:

  • Wajib upload file ke server pihak ketiga — resiko privasi buat dokumen sensitif
  • Dipaksa sign-up cuma buat pakai 1 fitur simpel
  • Hasil kena watermark kalau gak upgrade ke versi berbayar
  • Proses lambat karena harus upload lalu download ulang dari server
  • Banyak iklan yang mengganggu di tengah proses

Solusi

12+ Tools yang Berjalan Penuh di Browser

PekaTools memproses semua file langsung di device pengguna, tanpa backend:

  • Image Compressor, Resize, PNG/JPG/WebP Converter, Watermark
  • Merge PDF, Delete PDF Page, Image to PDF
  • QR Generator polos & dengan logo custom
  • Zero upload — file tidak pernah meninggalkan browser pengguna
  • Gratis tanpa batas, tanpa sign-up, tanpa watermark
  • Dark mode & fully responsive di semua device

Cara Kerja di Balik Layar

1

File Dibaca di Memory Browser

File API browser membaca file langsung dari device, tidak pernah dikirim keluar

2

Diproses via Canvas API / WASM

Kompresi & konversi gambar via Canvas API, PDF via pdf-lib, QR via library qrcode

3

Hasil Dibentuk sebagai Blob

Output diubah jadi Blob/Object URL sementara di memory browser

4

Trigger Download Native

Browser memicu unduhan langsung tanpa request HTTP ke server aplikasi

5

Memory Dibersihkan Otomatis

Object URL sementara di-revoke setelah tidak dipakai, mencegah memory leak

Tantangan & Pembelajaran

Skalabilitas 12+ Tools Tanpa Duplikasi

Tantangan: Menghindari copy-paste logic yang sama di banyak tool berbeda.

Solusi: Komponen reusable (UploadArea) + single source of truth data tool di satu file terpusat.

Build Gagal karena Library Browser-Only

Tantangan: Library pdfjs-dist memakai API browser (DOMMatrix) yang tidak ada saat prerender di server Vercel.

Solusi: Dynamic import dengan ssr: false khusus komponen yang bersangkutan.

Kompresi Gambar Tanpa Merusak Kualitas

Tantangan: Setting default kompresi terlalu agresif, hasil gambar jadi blur.

Solusi: Target ukuran dinamis berdasarkan file asli + kalibrasi initial quality.

Hapus Halaman PDF dengan Urutan yang Benar

Tantangan: Index halaman bergeser tiap kali satu halaman dihapus, salah hapus halaman lain.

Solusi: Hapus halaman dari index terbesar ke terkecil secara berurutan.

QR Code dengan Logo yang Tetap Terbaca

Tantangan: Menempelkan logo di tengah QR beresiko membuat kode tidak bisa di-scan.

Solusi: Error correction level tertinggi (H) + batasi ukuran logo maksimal 22% dari QR.
